# MAX · GREEN-API

React-приложение для отправки и получения текстовых сообщений в MAX через GREEN-API.

**Стек:** React 19, TypeScript strict, Vite, CSS Modules, Fetch API, Vitest, React Testing Library, ESLint, Prettier.

## Запуск и проверка

Требуются Node.js 22.12+ (рекомендуется 24, версия указана в `.nvmrc`), npm и современный браузер с поддержкой AbortSignal.any/timeout.

```bash
npm ci
npm run dev
```

Приложение доступно по адресу http://127.0.0.1:5173.

```bash
npm test              # тесты с HTTP-моками
npm run typecheck     # TypeScript
npm run lint          # ESLint
npm run format:check  # Prettier
npm run build         # production-сборка в dist/
npm run preview       # просмотр собранного приложения
```

## Настройка GREEN-API

1. Создайте аккаунт в мобильном MAX и отдельный инстанс **MAX** в [кабинете GREEN-API](https://console.green-api.com/).
2. Авторизуйте инстанс по QR-коду: в MAX откройте «Профиль → Устройства → Войти по QR-коду». При необходимости завершите 2FA в кабинете. Дождитесь состояния `authorized`.
3. В настройках инстанса очистите `webhookUrl`, включите входящие уведомления (`incomingWebhook: "yes"`) и сохраните изменения.
4. В приложении введите `idInstance`, `apiTokenInstance` и `apiUrl` из кабинета. Предзаполненный apiUrl — пример; замените его адресом своего инстанса.
5. Подключитесь, введите телефон РФ или Беларуси и откройте чат. Отправьте сообщение и ответьте из MAX — ответ появится в интерфейсе.

Используйте один клиент на инстанс: приложение потребляет всю очередь уведомлений, включая события других чатов.

## Реализация

- `src/services/` — HTTP-клиент с проверкой внешних данных, таймаутами и безопасными ошибками; последовательный цикл получения уведомлений.
- `src/hooks/` — состояние чата, отправка и управление жизненным циклом polling.
- `src/components/` — подключение, чат, история и ввод сообщения.
- `src/utils/` — нормализация телефона, парсинг, фильтрация и дедупликация.
- `src/test/` — HTTP-контракт, ошибки, очередь, отмена запросов, StrictMode и пользовательский сценарий.

Состояние хранится средствами React. Backend не используется: запросы идут напрямую в GREEN-API по HTTPS. Сервер инстанса должен поддерживать CORS для адреса приложения.

Подключение проверяется через `GetStateInstance`. Телефон нормализуется и передаётся в `CheckAccount`: возвращённый `chatId` используется без преобразований, номер телефона его не заменяет. `SendMessage` добавляет исходящее сообщение только после ответа с `idMessage`. Enter отправляет, Shift+Enter переносит строку. При ошибке черновик сохраняется, автоматической повторной отправки нет.

### Обработка очереди

`ReceiveNotification` ожидает событие до 30 секунд. После обработки вызывается `DeleteNotification`. Запросы выполняются последовательно, с паузой 100 мс между событиями и 1 с после пустого ответа. При сетевых ошибках, HTTP 429 и 5xx задержка повторов растёт от 1 до 30 секунд. Отключение отменяет запросы и таймеры; пробный цикл React StrictMode не запускает дополнительный fetch.

- Тексты всех чатов сохраняются в памяти; отображаются только сообщения активного чата. Дубликаты исключаются по паре `(chatId, idMessage)`.
- Поддерживаются обычный текст и `extendedTextMessage`. Остальные события с валидным конвертом пропускаются и подтверждаются.
- Повреждённые текстовые события и ошибки обработки останавливают polling без удаления уведомления. После устранения причины доступен ручной перезапуск.

## Ограничения

- Токен и история существуют только в памяти вкладки. Секретов в конфигурации сборки нет. По протоколу GREEN-API токен передаётся в URL запроса и виден в DevTools; не публикуйте сетевые логи с реальными данными.
- История теряется при отключении или перезагрузке. Предыдущая переписка, вложения, статусы доставки и исходящие сообщения с телефона не загружаются. Переключение чата очищает черновик.
- «Принято API» не подтверждает доставку в MAX. При потере ответа на отправку проверьте MAX перед ручным повтором: сообщение могло быть принято сервером.
- Поиск по телефону ограничен номерами РФ/РБ и настройками приватности MAX. Настройки инстанса приложение не меняет; отключение не разлогинивает аккаунт MAX.

## Проверка сценария

Для проверки обмена сообщениями подключите авторизованный инстанс, откройте чат по номеру телефона и отправьте текст. Ответьте из MAX и убедитесь, что ответ появился в чате один раз. Затем проверьте восстановление получения после потери сети и остановку запросов при отключении.

Автоматические тесты используют HTTP-моки и запускаются командой `npm test`.
